真核細胞的細胞質並非均勻的膠狀物，而是由細胞骨架（cytoskeleton）——一套遍布細胞質、連接細胞核與細胞膜的纖維與管狀網絡——所支撐。細胞骨架不僅賦予細胞形狀，也主導細胞運動、胞器運輸、細胞分裂與訊息傳遞等關鍵功能，並且是高度動態、可隨時組裝與拆解的結構。

13.1 細胞骨架的主要結構元件

細胞骨架的核心特徵是模組化（modularity）：少數幾種基本元件，在不同位置以不同排列方式組成各種細胞結構，就如同人體骨骼僅用骨頭、軟骨、肌腱、韌帶等有限元件建構出全身架構一樣。

真核生物的三種細胞骨架元件

電子顯微鏡與免疫螢光技術（immunofluorescence）確認了真核細胞中有三種主要的細胞骨架系統：微管（microtubule, MT）、微絲（microfilament, MF）與中間絲（intermediate filament, IF）。三者的直徑、組成蛋白與功能各不相同（見下表）。此外，酵母菌中發現的septin蛋白聚合物有時被稱為「第四種細胞骨架」，與細胞分裂時的收縮環（contractile ring）密切相關。

原核生物也有類似的細胞骨架系統

細菌與古菌同樣具有功能上類似微絲、微管、中間絲的聚合系統。例如：桿狀細菌中的MreB（類似肌動蛋白）維持細胞形狀並參與細胞分裂；FtsZ（類似微管蛋白）決定細菌分裂的位置；crescentin（類似中間絲蛋白）則調控某些細菌的細胞形狀。雖然這些蛋白質在胺基酸序列上與真核同源蛋白差異很大，但X光晶體繞射顯示其聚合後的整體結構高度相似，且都能結合相同種類的核苷酸（GTP、ATP）。

知識延伸

粒線體與葉綠體也會製造FtsZ蛋白，並定位於胞器分裂位置，這項發現支持了真核細胞胞器起源於內共生原核生物的理論。

細胞骨架是動態組裝與拆解的

細胞骨架最為人熟知的功能之一是驅動細胞運動：微絲是肌肉收縮纖維的核心成分，微管則構成纖毛與鞭毛（flagella）的結構骨幹。隨著顯微技術進步，科學家發現大多數細胞會依時間與位置動態地調控特定細胞骨架結構的組裝與拆解，這也是本章後續各節的核心主題。

13.2 微管 Microtubules

微管（MTs）是細胞骨架中最大的結構元件，功能主軸都圍繞著「移動」：無論是移動細胞內部的物質，或是移動細胞外部的液體。

兩種微管：胞質微管與軸絲微管

  • 胞質微管（cytosolic microtubules）：組織較鬆散、動態性高，負責維持軸突（axon）結構、決定植物細胞壁纖維排列方向、組成有絲分裂/減數分裂紡錘體，並引導胞器與囊泡的運輸方向。
  • 軸絲微管（axonemal microtubules）：高度有序且穩定，見於纖毛、鞭毛及其基部的基體（basal body）。

微管蛋白異二聚體：微管的建構單元

微管是外徑約25 nm、內徑約15 nm的中空圓柱，管壁通常由13條稱為原絲（protofilament）的線性聚合物並排組成。每個原絲的基本單位是異二聚體（heterodimer）——一分子α-tubulin加一分子β-tubulin以非共價方式緊密結合而成，正常情況下不會解離。

α-與β-tubulin雖然胺基酸序列僅約40%相同，立體結構卻幾乎一致，各自具有：(1) N端的GTP結合區、(2) 可被微管毒素秋水仙素（colchicine）結合的中段區域、(3) C端可與微管結合蛋白（MAP）交互作用的區域。由於所有原絲中二聚體方向一致，整條微管因此具有極性（polarity）——一端為正端(+)，一端為負端(−)。

示意圖：微管橫截面由13條原絲圍成中空圓柱（左）；單一原絲由αβ-tubulin異二聚體重複堆疊、具方向性，因此整條微管有正端與負端之分（右）。（改繪自 Figure 13-3）

大多數生物具有多種α-、β-tubulin同型體（isoform），這些同型體主要在C端序列上有差異，可能影響其與不同蛋白質的交互作用；tubulin也可經化學修飾（如乙醯化）而形成較穩定的微管。

胞質微管通常為13原絲的單管（singlet）；部分軸絲微管則更複雜，形成雙聯管（doublet）或三聯管（triplet）——由一條完整的A管與一到兩條不完整的B、C管組成，見於纖毛/鞭毛及基體、中心粒。

微管兩端組裝速率不同：組裝速度較快的一端稱正端（plus end），較慢的一端稱負端（minus end）。當游離tubulin濃度介於正端與負端的臨界濃度（critical concentration）之間時，正端持續聚合、負端持續解聚，形成跑步機效應（treadmilling）——次單元從正端加入，沿著微管「移動」後最終從負端脫離。

機制：GTP帽與動態不穩定性（Dynamic Instability）

每個tubulin異二聚體結合兩個GTP：α-tubulin上的GTP不會被水解，β-tubulin上的GTP則會在加入微管後逐漸水解為GDP。Mitchison與Kirschner提出的動態不穩定模型指出，微管族群同時存在「生長」與「縮短」兩種狀態：

GTP-tubulin快速加入正端 → 形成「GTP帽」
→
GTP帽穩定微管尖端，持續生長
→
游離tubulin濃度下降，GTP水解速度追上添加速度
→
GTP帽消失 →「災難」catastrophe，快速解聚
→
若重新形成GTP帽 →「拯救」rescue，恢復生長

災變（catastrophe）在正端更容易發生，且游離tubulin濃度愈高，災變機率愈低、拯救機率愈高。

微管組織中心（MTOC）：決定微管從哪裡長出來

細胞內微管通常由微管組織中心（microtubule-organizing center, MTOC）發起組裝，並錨定微管的一端。動物細胞間期最重要的MTOC是位於細胞核附近的中心體（centrosome），內含一對互相垂直的中心粒（centriole），其管壁由九組三聯管構成。中心體周圍散布的中心粒周物質（pericentriolar material）含有γ-tubulin，會與GRiP蛋白組成環狀的γ-tubulin環複合體（γ-TuRC），作為微管成核位點。

中心體錨定微管的負端（−），微管由此向細胞周邊延伸，正端（+）朝外，是細胞內微管動態變化最活躍的位置。（改繪自 Figure 13-8/13-9）

並非所有細胞都以中心體作為MTOC——例如高基氏體（Golgi apparatus）也是重要的非中心體MTOC，協助組織囊泡運輸相關的微管；植物與大多數真菌細胞則完全沒有中心粒，顯示中心粒並非MTOC形成的必要條件。有絲分裂期間，MTOC的微管成核活性會顯著提升，以利紡錘體形成。

研究技術：如何觀察細胞骨架的動態？

科學家利用可逆的化學干擾劑（如秋水仙素、nocodazole）搭配「沖洗實驗（wash-out experiment）」——先讓藥物抑制微管組裝，再將藥物洗去，觀察微管如何重新從中心體長出，藉此證實中心體錨定微管負端。此外，將螢光標記的tubulin或GFP標記的+TIP蛋白（如EB1）導入活細胞並以螢光顯微鏡即時攝影，是證實「動態不穩定性」確實發生在活細胞內的關鍵方法。

13.3 微絲 Microfilaments

微絲（MFs）直徑約7 nm，是三種細胞骨架元件中最細的一種，最為人熟知的功能是與肌凝蛋白（myosin）共同作用產生肌肉收縮，但也廣泛參與細胞遷移、變形蟲運動、細胞質流動、胞質分裂（cytokinesis）及細胞形狀維持。

肌動蛋白：微絲的建構單元

肌動蛋白（actin）是真核細胞中含量最豐富的蛋白質之一，單體形式稱G-actin（球狀肌動蛋白），聚合後稱F-actin（絲狀肌動蛋白）。G-actin單體在適當條件下以兩股螺旋方式纏繞聚合，約每13.5個單體形成半圈螺旋。肌動蛋白依序列可分為肌肉型（α-actin）與非肌肉型（β-、γ-actin），後兩者在細胞內的分布位置與交互作用蛋白也有所不同。

微絲的組裝、極性與跑步機效應

如同tubulin，G-actin的聚合也經歷遲滯期（成核）與延伸期。微絲同樣具有極性：生長較快的一端稱倒鉤端／正端（barbed/plus end），生長較慢的一端稱尖端／負端（pointed/minus end）——此命名來自肌凝蛋白S1片段結合微絲後所產生的箭頭狀圖案。細胞內G-actin幾乎只加到正端，因為profilin蛋白會阻止其加到負端。ATP會在單體加入後逐漸水解為ADP，因此微絲末端多為ATP-actin，主體則多為ADP-actin。

肌動蛋白結合蛋白：精細調控微絲的長度與組織

細胞利用多種肌動蛋白結合蛋白（actin-binding proteins）來控制微絲的聚合位置、長度與排列方式：

  • 單體調控蛋白：thymosin β4會螯合G-actin使其無法聚合；profilin則促進G-actin加到正端；ADF/cofilin促進負端單體週轉，並可切斷微絲、產生新的正端。
  • 成核蛋白：Arp2/3複合體在既有微絲側邊形成分支狀新絲（受WASP家族蛋白活化）；formin則以二聚體形式結合正端，持續性地拉長絲狀結構，並可招募profilin-actin複合物。
  • 端帽蛋白：CapZ封住正端阻止加成/流失；tropomodulin封住負端。
  • 交聯蛋白：filamin將交錯的微絲「拼接」成三維網狀結構。
  • 切斷蛋白：gelsolin切斷微絲並為新暴露的正端加帽，使皮質凝膠軟化液化。
  • 束狀化蛋白：α-actinin見於focal adhesion；fascin使指狀偽足內的微絲緊密成束。

微絨毛（Microvilli）：高度有序的肌動蛋白束範例

腸道黏膜細胞表面密布的微絨毛（microvillus），核心由緊密的微絲束構成：正端朝向頂端、嵌入電子緻密斑；肌動蛋白束狀化蛋白fimbrin與villin將微絲緊密交聯，並以myosin I與calmodulin將微絲側向連接至細胞膜。微絨毛基部延伸入由myosin II與spectrin構成的終端網（terminal web），賦予微絨毛穩固的直立結構，可使細胞表面積增加約20倍，有利於營養吸收。

連接肌動蛋白與細胞膜的蛋白

微絲要能對細胞膜施力，需靠連接蛋白錨定於跨膜蛋白，例如band 4.1超家族（含ezrin、radixin、moesin）。紅血球細胞膜下方由spectrin網絡支撐，並經短鏈肌動蛋白交聯，再由ankyrin與band 4.1連接至跨膜蛋白，賦予紅血球膜強度與彈性。

GEF（guanine-nucleotide exchange factor）促進GDP換成GTP，活化Rho；GAP（GTPase-activating protein）促進GTP水解，使其失活；GDI（guanine-nucleotide dissociation inhibitor）則將不活化的Rho家族蛋白隔離於胞質中，阻止其定位到細胞膜發揮作用。

此外，膜上的磷脂醯肌醇雙磷酸（PIP₂）可結合profilin、CapZ、ezrin等蛋白並調節其活性，是另一層調控肌動蛋白組裝的機制。

臨床連結：李斯特菌如何劫持肌動蛋白殺人

Listeria monocytogenes（李斯特菌）是孕婦飲食中需避免生食冷肉、未殺菌乳酪的原因之一，感染可能導致流產或新生兒嚴重感染。此菌的致病策略正是「劫持」宿主細胞的肌動蛋白聚合機制：

1. 表面蛋白internalin A結合宿主E-cadherin → 被吞噬
→
2. Listeriolysin O破壞吞噬體膜 → 逃入細胞質
→
3. 在細胞質中分裂增殖
→
4. 表面蛋白ActA活化Arp2/3，於菌體後方聚合出肌動蛋白「火箭」推進
→
5. 推入鄰近細胞，形成雙層膜
→
6. 感染循環重新開始

此機制與細胞前緣（leading edge）的肌動蛋白聚合原理相同，李斯特菌可藉此以每分鐘22 μm的速度移動，並在感染細胞的保護下躲避宿主免疫系統偵測。

觀念釐清：CONCEPT CHECK 13.3

若以phalloidin處理培養的纖維母細胞，細胞會停止移動——這是因為phalloidin使既有微絲維持穩定、無法解聚，導致細胞前緣所需的肌動蛋白動態重組（聚合／解聚循環）被阻斷，說明細胞爬行必須依賴微絲的持續組裝與拆解，而非單純「有微絲存在」即可。

13.4 中間絲 Intermediate Filaments

中間絲（IFs）直徑約8–12 nm，介於微管與微絲之間。中間絲不存在於植物細胞質中，但廣泛分布於動物細胞，扮演結構支撐與承受張力的角色。與微管、微絲不同，中間絲是細胞骨架中最穩定、最不易溶解的成分——以清潔劑或高/低離子強度處理細胞後，微管與微絲多半消失，但IF網絡仍保留原本形狀，顯示其可能作為整個細胞骨架的支撐骨架。

中間絲蛋白具有組織特異性

不同於微管、微絲蛋白在演化上高度保守，中間絲蛋白依組織種類差異極大，可分為六大類：

中間絲由纖維狀次單元逐步組裝

與球狀的actin、tubulin不同，中間絲的基本單位是纖維狀（fibrous）二聚體，其中央桿狀結構域由四段α螺旋組成。組裝過程如下：

(a) 兩條IF多肽以中央結構域纏繞成二聚體
→
(b) 兩個二聚體側向錯位排列成四聚體（原絲）
→
(c) 原絲頭尾及側向交錯組裝
→
(d) 完整中間絲：任一橫切面約8條原絲厚

中間絲的組裝：由纖維狀二聚體逐步堆疊成完整的中間絲，全程不具極性方向。（改繪自 Figure 13-23）

中間絲賦予組織機械強度

中間絲多分布於承受機械應力的區域，具有承受張力（tension-bearing）的功能。基因改造小鼠角質細胞中的角蛋白若被破壞，皮膚細胞會變得脆弱易破——人類自然發生的角蛋白突變也會導致水疱性表皮鬆解症（epidermolysis bullosa simplex）等皮膚疾病。核纖層（由lamin A、B、C構成）會在有絲分裂開始時因磷酸化而解體，分裂後再去磷酸化重組，顯示中間絲並非靜態結構，而是可動態重塑的。IFs對化學藥劑相對不敏感，但丙烯醯胺（acrylamide）——常見於部分加工食品與工業用品——可破壞部分IF網絡，機制尚不完全清楚。

13.5 細胞骨架是機械整合的網絡

雖然本章分別介紹了微管、微絲、中間絲三種元件，但實際上細胞的整體力學特性來自三者協同作用：

本章易混淆概念比較③　三大細胞骨架元件的力學角色
元件力學特性差異重點
微管 (MT)抵抗細胞受壓時的彎曲（壓縮力）類似「支柱」
微絲 (MF)作為收縮元件，產生張力類似「拉索」，主動出力
中間絲 (IF)具彈性，承受拉伸應力類似「彈性繩」，被動緩衝

三者的機械整合，是透過連接蛋白家族spectraplakin（如plectin）達成——plectin同時具有結合IF、MF、MT的位點，將三套系統交聯成具有機械韌性的整體網絡。

Plectin作為交聯樞紐，連結微管、微絲與中間絲三套系統，形成機械整合的細胞骨架網絡。（改繪自 Figure 13-24）

# Key Takeaways

  • 三大結構元件：微管（MT，25 nm，tubulin，GTP）、微絲（MF，7 nm，actin，ATP）、中間絲（IF，8–12 nm，組織特異性蛋白，無核苷酸結合）。
  • MT與MF皆具極性（正端/負端），IF則無極性；正端通常生長較快。
  • 動態不穩定性（dynamic instability）是微管的核心概念：GTP帽存在 → 生長；GTP帽消失 → 災變（catastrophe）快速解聚；重新形成GTP帽 → 拯救（rescue）。
  • 中心體／MTOC錨定微管負端，γ-TuRC負責微管成核；MT正端朝細胞周邊延伸。
  • 秋水仙素使微管解聚、紫杉醇使微管過度穩定——兩者機制相反但都能阻斷有絲分裂，是必考比較重點。
  • 肌動蛋白結合蛋白依功能分為：單體調控（thymosin β4、profilin）、成核（Arp2/3、formin）、加帽（CapZ、tropomodulin）、交聯（filamin）、切斷（gelsolin）、束狀化（α-actinin、fascin）。
  • Rho家族GTPase：Rho→應力纖維；Rac→葉狀偽足；Cdc42→指狀偽足；GEF活化、GAP去活化、GDI隔離，是訊息傳遞的重要調控範例。
  • 中間絲最穩定、耐清潔劑，具組織特異性，臨床可用於腫瘤來源鑑定（IF typing）。
  • Plectin等spectraplakin蛋白將MT、MF、IF交聯，形成機械整合的細胞骨架，分別提供抗壓（MT）、張力收縮（MF）與彈性抗拉（IF）功能。
  • 李斯特菌利用ActA活化宿主Arp2/3系統形成肌動蛋白「火箭」，是理解肌動蛋白聚合機制常見的臨床應用實例。
