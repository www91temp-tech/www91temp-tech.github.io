23.1 化學訊息與細胞受體（Chemical Signals and Cellular Receptors）

幾乎所有細胞都具備感知並回應特定化學訊息的能力。細胞除了「接收」訊息，也會「發出」訊息：有些訊息需要細胞直接接觸才能傳遞，有些則可以擴散到鄰近甚至遙遠的細胞。

訊息傳遞的關鍵組成

依作用距離分類的四種化學訊息

訊息分子常依「產生地點」與「作用目標」之間的距離來分類：

內分泌 Endocrine
荷爾蒙（hormone）

由內分泌組織分泌，經血液循環運送到遠處的標的組織（target tissue）。

旁分泌 Paracrine
局部調節物（local mediator）

如生長因子，擴散作用於鄰近細胞，作用範圍短。

自分泌 Autocrine
作用於自身

細胞分泌的訊息分子回過頭作用在分泌它的同一顆細胞上。

近分泌 Juxtacrine
需要細胞接觸

訊息分子鑲嵌在細胞膜上，必須與鄰近細胞直接physical contact才能傳遞訊息。

（對應原文 Figure 23-1）

受體與配體的結合

訊息分子（primary messenger）到達標的細胞後，會與細胞表面或細胞內的受體（receptor）結合，此時該分子稱為配體（ligand，源自拉丁文 ligare「結合」）。配體與受體之間形成多個弱的非共價鍵（noncovalent bond），受體的結合口袋（binding pocket）形狀與胺基酸側鏈排列決定了結合的專一性。

1配體與受體結合Receptor-ligand binding，訊息分子作為「一級傳訊者（primary messenger）」
→
2訊息傳遞（signal transduction）細胞質中常經由二級傳訊者（second messenger）放大並傳遞訊息
→
3細胞反應改變細胞功能，或訊息進入細胞核改變基因表現

（對應原文 Figure 23-2：訊息傳遞的整體流程）

重要概念：preprogrammed response（預設程式化反應）

受體與配體結合後，受體構型改變或發生群聚（clustering），進而啟動細胞內「早已準備好」的一連串反應。細胞會依照自身過去接收過的訊號史（例如先前表現了哪些基因），決定現在能對哪些訊號產生反應。

受體結合的量化分析：解離常數 Kd

受體與配體的結合可以用類似酵素與受質的方式來描述。當配體濃度增加，愈來愈多受體被佔據（occupied），直到達到飽和（saturation）。

解離常數（dissociation constant, Kd）定義為使一半受體被佔據時所需的游離配體濃度。Kd 愈小 → 親和力（affinity）愈高；Kd 愈大 → 親和力愈低。這與酵素動力學中的 Km 概念類似。

臨床/藥理相關名詞

致效劑（agonist）：能與受體結合並「活化」受體的藥物或化合物，模擬天然配體的作用。
拮抗劑（antagonist）：能與受體結合，卻不會活化受體，反而阻止天然配體發揮作用，達到抑制效果。

受體去敏感化（receptor desensitization）

細胞感受的其實是配體濃度的「變化」而非固定濃度。若配體長時間存在，細胞會降低反應，稱為去敏感化，主要透過兩種方式：

  1. 受體數量減少：受體媒介的胞吞作用（receptor-mediated endocytosis）將細胞表面受體內化。
  2. 受體本身的生化修飾：如磷酸化，改變受體對配體的親和力或傳訊能力。

訊息放大（Signal Amplification）

訊息傳遞路徑最重要的特性之一，就是能將極少量的配體訊號逐級「放大」。以肝細胞對腎上腺素（epinephrine）的反應為例：

細胞表面與細胞內的四大類受體

親水性配體（蛋白質、胜肽、胺基酸衍生物）通常結合膜上受體；疏水性配體（如類固醇）則可穿越細胞膜，結合細胞質或細胞核內受體。

(a)
配體閘控離子通道

Ligand-gated ion channel。配體結合後通道開啟，離子（如 Ca²⁺）直接流入細胞。

(b)
G蛋白偶聯受體 GPCR

配體結合活化 G 蛋白（GTP 態），進而活化酵素、產生二級傳訊者（cAMP、IP₃）。

(c)
酵素偶聯受體

如受體酪胺酸激酶：受體本身被磷酸化，活化 Ras 及下游激酶。

(d)
核受體

疏水性配體（如類固醇）穿膜進入細胞，與細胞質受體結合後進入細胞核，改變基因表現。

23.2 G蛋白偶聯受體（G Protein–Coupled Receptors, GPCR）

GPCR 的結構與 G 蛋白活化循環

GPCR 的共同特徵是七次穿膜的 α 螺旋（seven transmembrane α helices），N端在細胞外、C端在細胞質。細胞質環路能與特定 G 蛋白（guanine-nucleotide binding protein）作用。GPCR 家族成員包括嗅覺受體、β-腎上腺素受體，以及臨床上極重要的類鴉片受體（opioid receptor）（嗎啡的作用標的）。

異三聚體 G 蛋白（heterotrimeric G protein）

由 Gα、Gβ、Gγ 三個次單元組成。Gα 結合 GDP 時處於「關閉」狀態；結合 GTP 時處於「開啟」狀態並與 Gβγ 分離。Gs 為刺激型（stimulatory），Gi 為抑制型（inhibitory）。

1靜止態受體未結合配體；Gα-GDP 與 Gβγ 結合在一起
→
2配體結合受體Gα 釋出 GDP，換上 GTP
→
3次單元分離Gα-GTP 與 Gβγ 分開，各自可作用於標的蛋白
→
4Gα 水解 GTPGTP → GDP + Pi，Gα 失去活性
→
5重新組合Gα-GDP 再與 Gβγ 結合，回到步驟 1（循環）

Gβγ 訊息傳遞實例：蕈毒鹼型乙醯膽鹼受體

乙醯膽鹼（Ach）結合心臟的蕈毒鹼受體後，活化的 Gβγ 直接作用於鉀離子通道使其開啟，降低心跳速率；Ach 消失後，α、βγ 重新結合，通道關閉。

cAMP：由 G 蛋白調控生成的二級傳訊者

環腺苷單磷酸（cyclic AMP, cAMP）由膜上酵素腺苷酸環化酶（adenylyl cyclase）將 ATP 轉換而成；再由細胞質中的磷酸二酯酶（phosphodiesterase）水解為 AMP 而失活。

1ATP受質
→
2腺苷酸環化酶（活化態）被 Gsα-GTP 活化
→
3cAMP + PPi產物
→
4磷酸二酯酶cAMP + H₂O → AMP，訊號終止

2cAMP 結合調節次單元調節次單元構型改變
→
3催化次單元游離、活化可磷酸化多種標的蛋白的 Ser／Thr 位點

G蛋白訊息路徑失常與人類疾病

Clinical Correlation：霍亂與百日咳

霍亂（cholera）：霍亂弧菌毒素會化學修飾 Gs，使其無法水解 GTP，導致 Gs 持續活化、cAMP 濃度可高達正常的 100 倍，過度活化囊性纖維化氯離子通道（CFTR），造成腸道大量分泌氯離子、鈉離子與水分，引發嚴重脫水。治療方式為口服補液療法（含葡萄糖，可透過 Na⁺/glucose 共同運輸蛋白幫助鈉回收）。

百日咳（pertussis）：百日咳桿菌毒素作用於抑制型 Gi 蛋白，使其失去抑制腺苷酸環化酶的能力，導致肺部液體堆積、劇烈咳嗽。

IP3 與 DAG：磷脂醯肌醇路徑

另一群 G 蛋白（Gq）活化磷脂酶C（phospholipase C），將膜脂質 PIP2（phosphatidylinositol-4,5-bisphosphate）切割成兩個二級傳訊者：

1配體結合受體 → Gq活化GDP 換 GTP，α與βγ分離
→
2磷脂酶Cβ 活化切割 PIP₂
→
3IP₃（水溶性，進入細胞質）結合 ER 上 IP₃受體，促使 Ca²⁺ 釋放
4DAG（留在膜上）活化蛋白激酶C（PKC）
對應原文 Figure 23-12／23-13：PIP₂ → IP₃ + DAG

PKC 活化與多種細胞功能有關：細胞生長刺激、離子通道調控、細胞骨架改變、胞內 pH 上升、蛋白分泌等。

機制重點：鈣誘發鈣釋放（calcium-induced calcium release）

IP₃ 受體與 Ryanodine 受體本身也對 Ca²⁺ 敏感：少量 Ca²⁺ 進入細胞質後，會進一步刺激 ER 釋出更多 Ca²⁺，如同水波一樣向外擴散放大訊號。此機制是受精卵鈣波（見下方）的關鍵。

受精時的鈣釋放：卵子活化

精卵結合後數十秒至數分鐘內，鈣離子波從精子進入處開始擴散全卵（詳見章首插圖）。此鈣波導致兩件重要事件：

  1. 皮質顆粒胞吐（cortical granule exocytosis）：改變卵膜（vitelline envelope），形成「慢性多精子阻擋（slow block to polyspermy）」，防止多重受精（先前尚有快速阻擋：質膜短暫去極化）。
  2. 卵子活化（egg activation）：恢復代謝活動、重組卵內部結構，啟動胚胎發育。

鈣結合效應蛋白：鈣調蛋白（calmodulin）

鈣調蛋白形似一條有彈性的「手臂」，兩端各有一個「手掌」，可各結合 2 個 Ca²⁺（共4個）。結合後構型改變，形成活化的鈣-鈣調蛋白複合體，像蛇形手環一樣纏繞包裹標的蛋白（如激酶、磷酸酶），進而調控其活性。鈣調蛋白在胞質 Ca²⁺ 升到約 1.0 μM 時結合鈣，降回 0.1 μM 時釋放，恰好對應細胞內鈣濃度的生理範圍。

研究工具：鈣指示劑與鈣離子載體（Key Technique）

鈣指示劑（calcium indicator），如螢光染料 fura-2 或基因編碼的 cameleon 蛋白，可用來「觀察」細胞內鈣濃度何時何地升高。
鈣離子載體（calcium ionophore），如 ionomycin、A23187，可使膜對鈣離子通透，在沒有生理刺激下人為釋放胞內鈣儲存，用來測試「鈣升高是否足以引發某個細胞反應」（因果驗證，而非只是相關）。

想一想（Concept Check 23.2）

靜息細胞的 Ca²⁺ 濃度約 10⁻⁷ M，遠低於 Na⁺（約 10⁻³ M）。為什麼 Ca²⁺ 比 Na⁺ 更適合作為二級傳訊者？

23.3 酵素偶聯受體（Enzyme-Coupled Receptors）

生長因子與受體激酶

細胞增殖除了需要營養，還需要額外訊號刺激。血清（serum，血漿凝血後的清液）中富含生長因子（growth factor），可刺激細胞分裂——這是因為凝血過程中血小板釋放了血小板衍生生長因子（PDGF）。許多生長因子（PDGF、胰島素、EGF、FGF、神經生長因子等）都透過受體酪胺酸激酶（receptor tyrosine kinase, RTK）作用。

RTK 的群聚與自體磷酸化

RTK 通常只有一段穿膜區，胞外為配體結合區，胞內含酪胺酸激酶活性區。配體結合後 RTK 發生雙體化（dimerization）／群聚（clustering），彼此磷酸化對方的酪胺酸，稱為自體磷酸化（autophosphorylation）。

1配體結合如 EGF 單體結合各自的受體
→
2受體雙體化兩個受體聚在一起
→
3交互磷酸化彼此的酪胺酸激酶磷酸化對方的酪胺酸殘基
→
4形成 SH2 結合位點磷酸酪胺酸可招募含 SH2 domain 的胞質蛋白

此外，RTK 也能活化磷脂酶Cγ（PLCγ，與 GPCR 活化的 PLCβ 為不同亞型），以及PI 3-激酶（phosphatidylinositol 3-kinase），後者對細胞增殖與遷移相當重要。

用突變解析RTK訊息路徑：果蠅複眼

果蠅複眼每個小眼（ommatidium）需要 R8 細胞上的配體 Boss 活化 R7 前驅細胞上的受體 Sevenless（Sev），R7 才能正常分化。此系統常用來以基因遺傳學驗證訊息路徑順序：

  • Sev 缺失 → 無 R7 細胞（受體必要）
  • Sev 缺失，但 Ras 帶有持續活化型突變 → R7 仍可形成（證明 Ras 在 Sev 下游，可繞過受體本身）
Clinical Correlation：顯性負性突變與人類疾病

FGFR（纖維母細胞生長因子受體）需以雙體形式運作。若細胞同時表現正常與顯性負性（dominant negative）突變受體，正常受體與突變受體配對後整組失去功能。人類 FGFR-3 的組成型活化突變（constitutively active mutation）會造成最常見的侏儒症——軟骨發育不全（achondroplasia）；更嚴重的單一胺基酸突變則導致致死性侏儒症（thanatophoric dysplasia）。

受體絲胺酸/蘇胺酸激酶：TGFβ／Smad 路徑

TGFβ 家族生長因子透過磷酸化絲胺酸／蘇胺酸（serine/threonine）而非酪胺酸來傳訊，調節細胞增殖、細胞凋亡與胚胎發育。

→

→
4R-Smad + Smad4複合體進入細胞核，調控基因表現

其他酵素偶聯受體

酪胺酸磷酸酶受體：移除酪胺酸上的磷酸基，反向調控 RTK 活性；許多此類受體的配體仍未知。鳥苷酸環化酶（guanylyl cyclase）受體：功能類似腺苷酸環化酶，但產物是 cGMP 而非 cAMP，在視網膜光受器、腸道液體調節與血管舒張中扮演重要角色。

23.4 訊息整合（Signal Integration）

支架蛋白促進訊息傳遞的專一性

細胞常需要把訊息傳遞侷限在特定位置與特定路徑上，支架蛋白（scaffold protein）能將多個訊息傳遞成分組裝成大複合體，提高反應效率並避免訊號亂竄。例如 Ksr 蛋白可將 Raf、MEK、MAPK 固定在一起。

實例：酵母交配路徑（yeast mating pathway）

單倍體酵母 a 型細胞分泌 a factor，α 型細胞分泌 α factor，各自結合對方細胞上的 GPCR。活化的 Gβγ 招募支架蛋白 Ste5，將 MEKK → MEK → MAPK 級聯固定在一起，最終活化交配相關基因表現，兩細胞融合成二倍體。此例說明訊息路徑的組件可以「混合搭配」：GPCR 接在細胞表面，卻連接到原本屬於 RTK 系統的 MAPK 級聯。

訊息串聯（signaling crosstalk）

細胞同時暴露於多種訊號，各路徑並非彼此獨立。串聯可能發生在：

層級一
共用二級傳訊者

如 Ca²⁺、cAMP 可被多條路徑共同產生或使用。

層級二
共用蛋白激酶

PKA、PKC、MAPK、鈣調蛋白依賴激酶彼此互相磷酸化調控。

層級三
共同標的蛋白磷酸化

不同路徑的激酶可磷酸化相同的標的蛋白。

層級四
基因表現整合

多路徑訊號最終匯聚影響同一組基因的轉錄。

（對應原文 Figure 23-24：訊息串聯示意）細胞訊息傳遞最好被視為一張複雜的生化網路，而非彼此獨立的直線路徑。

想一想（Concept Check 23.4）

已知生長因子透過 RTK 促進細胞快速分裂；腎上腺素則活化腺苷酸環化酶產生 cAMP；而 PKA 會抑制 Raf 蛋白。若同時給予腎上腺素與生長因子，你預期細胞分裂速率會如何變化？
提示：PKA 抑制 Raf，而 Raf 是 Ras-MAPK 路徑中生長因子訊號傳遞的關鍵一環——這正是跨路徑串聯（crosstalk）造成拮抗效應的例子。

# Key Takeaways

  • 四種距離分類：內分泌（endocrine）走血液、旁分泌（paracrine）局部擴散、自分泌（autocrine）作用自身、近分泌（juxtacrine）需細胞接觸。
  • Kd（解離常數）是使一半受體被佔據時的配體濃度，數值越小代表受體對配體的親和力越高。
  • 訊息傳遞四大受體類型：配體閘控離子通道、GPCR、酵素偶聯受體（如RTK）、核受體，各自有不同的訊息傳遞邏輯。
  • GPCR 核心機制：配體結合 → Gα 由GDP換GTP → Gα與Gβγ分離並各自作用 → Gα水解GTP後訊號終止。
  • 兩大主要二級傳訊者路徑：①Gs/Gi → 腺苷酸環化酶 → cAMP → PKA；②Gq → 磷脂酶C → IP₃（釋放Ca²⁺）與DAG（活化PKC）。
  • 疾病機制必考：霍亂毒素鎖定Gs「恆常開啟」；百日咳毒素抑制Gi的抑制功能——兩者都導致cAMP異常升高，但作用的G蛋白種類相反。
  • RTK 訊號路徑：配體結合 → 受體雙體化、自體磷酸化 → SH2蛋白（GRB2）招募 → Sos（GEF）活化Ras → Raf-MEK-MAPK級聯 → 調控基因表現。
  • TGFβ／Smad 路徑使用絲胺酸/蘇胺酸激酶受體，經R-Smad與Smad4複合體直接進入細胞核調控轉錄，機制上與RTK-Ras路徑截然不同。
  • 訊息整合：支架蛋白（如Ksr、Ste5）將訊息組件侷限在特定位置；訊息串聯（crosstalk）可發生在二級傳訊者、激酶、標的蛋白、基因表現等多個層次。
  • 荷爾蒙與長程訊息：腎上腺素性荷爾蒙走GPCR（α型→Gq、β型→Gs）；胰島素走RTK-PI3K-Akt路徑；類固醇荷爾蒙走核受體；一氧化氮（NO）以cGMP路徑舒張血管，是氣體訊號分子的代表。
